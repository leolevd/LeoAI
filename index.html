Welcome to my little ai experiment! This is a proxy that enables you to use ai models for free. As more models are used up to their max, the wait time may become longer. I created this proxy for a simple way to access ai models, use them, and integrate them into projects. The time, however, can be a problem, since it will take longer to get a response as more models get used up etc etc.

This proxy forwards requests to NVIDIA, Gonka Broker, Kilo, or Vercel. Provider data handling varies, and fallback requests may reach more than one provider. Please do not submit sensitive information. Read the Privacy Policy for details about providers and local data handling, and the Terms of Service.

Python

# The usage is simple:
# you need a dict containing field "messages"
# everything else will be ignored
# You can't pick models because im using different services that don't share same models
# For example:
payloaddict = {
    "messages": [
        {"role": "system", "content": "Ur a meowy assistant"},
        {"role": "user", "content": "tell me a joke"}
    ]
}
import requests
print(requests.post("https://ai.leolevd.dev/api/v1/chat/completions", json=payloaddict).json())
