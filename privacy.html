Privacy Policy

Last updated: 18 November 2026

Before you send a request

I am leolevd, the operator of this AI proxy. This page describes the current app's data handling and the external providers used to answer requests.

I do not collect your data for my own use or store your conversations. The proxy temporarily processes requests to provide responses and prevent abuse. External AI providers handle the data sent to them under their own policies, described below.

Do not put passwords, API keys, confidential documents, or sensitive personal information in messages. Optional proxy API keys belong only in the Authorization header. This service does not guarantee zero data retention across its providers.

What is sent to providers

The proxy receives your request and forwards its JSON body, including messages, conversation history, and any other fields you include, to an AI provider to generate a response. It replaces the model field with the configured model; it does not anonymize or remove personal information from the body.

The current provider order is NVIDIA, Gonka Broker, Kilo, then Vercel. If a provider returns an unsuccessful HTTP status, the proxy tries the next provider. The same request can therefore reach several providers, even if you receive only one response or an error.

Providers receive the proxy's API credentials and network connection, rather than your incoming request headers. Any identifying information you include in the request body is still forwarded. Gateway providers may pass requests to additional inference providers.

How I handle data

  • Messages and responses: the app processes these in server memory to forward requests and return answers. It has no database or file storage for chat history and does not save prompts or responses as conversation history.
  • Rate limiting: the app uses the client IP address visible to the server to maintain temporary counters, enforcing 10 requests per minute for unauthenticated access. Optional valid API keys use a key identifier instead, with a higher limit (60 requests per minute by default, configurable by the operator). Counters are stored in process memory by default and reset on restart; deployments may configure a shared counter backend such as Redis. Counter expiry follows the rate-limit window.
  • Optional API keys: free access requires no key or account. For issued keys, the operator stores keys in plain text in a private JSON configuration file until they are removed. The app reads this file to authenticate requests and uses a hashed key identifier for rate limiting. Your incoming authorization header is not forwarded to AI providers. Removing a key revokes it for subsequent requests; deployment backups may retain earlier copies.
  • Diagnostic logs: the app prints provider names and HTTP error status codes, not provider response bodies or message content. Server access logs may also include IP addresses, request paths, times, and status codes.
  • Log retention: no log storage is configured and access logs are not retained by this app. Hosting infrastructure may independently capture server output or access logs; this statement applies to the app's own storage.
  • Cookies and analytics: the current pages do not set cookies, use browser storage, or include analytics scripts. No user account is required by this proxy.

Providers and their data policies

These summaries reflect the sources linked below as reviewed on the date above. Provider terms, selected models, and account settings can change. Unconfirmed retention periods are not guarantees that data is deleted.

NVIDIA

NVIDIA's API Trial Terms describe session-based processing with exceptions for particular services and security or abuse monitoring. Section 3.3 also allows collection of inputs and outputs to improve products, including AI models. There is no single verified retention period for this proxy's chat requests. The 30/90-day periods in those terms concern specific services, including fine-tuning, and are not a general chat retention promise.

NVIDIA API Trial Terms (sections 2 and 3) · NVIDIA Privacy Policy

Gonka Broker

The configured Gonka service is Gonka Broker, which routes inference through the decentralized Gonka network. Gonka Broker states that it does not store prompts or completions, and keeps request counts, token counts, timestamps, and price for billing and abuse prevention. Its homepage does not specify how long that metadata is retained. This statement is about the broker; it is not an independently verified retention guarantee for every network participant.

Gonka Broker's data-handling statement

Kilo Gateway

Kilo routes requests to inference providers and publishes training and retention policies for all 126 providers in its directory at the time of this update. Its privacy policy describes processing request metadata for authentication, routing, and billing. Prompt retention and training rules vary by downstream provider; the linked directory identifies those providers and their policies. A specific retention period and zero-retention configuration for this proxy have not been confirmed.

Kilo Privacy Policy · Kilo provider retention and training policies

Vercel AI Gateway

Vercel routes requests to model providers and offers optional zero data retention and prompt-training controls. The proxy does not itself enforce those controls, and account-level settings have not been confirmed. Do not assume those protections are enabled; downstream retention depends on the provider and applicable settings. A fixed retention period for this route has not been confirmed.

Vercel's retention and training controls

Empero (currently disabled)

Empero is a German AI research lab offering one model through its free endpoint. At the time of this update, that endpoint displays "MAINTENANCE, endpoint offline". It has been removed from the active fallback chain, so this proxy does not currently send requests to Empero.

Your choices and deletion

Remove identifying or confidential details before submitting a request. This proxy does not offer a provider-selection or training-opt-out control of its own. Your chat client may separately store history; check its settings and privacy policy.

There is no stored chat-history account to delete in this app. If you were issued an optional API key, ask the operator who supplied it to revoke it by removing it from the private configuration file. This does not mean that diagnostic logs or provider-held records are deleted. Provider privacy pages describe their own contact and data-rights processes; requests sent through this proxy use the operator's provider account, so a provider may require the operator's involvement. Deleting local client history does not delete records already sent to providers.
